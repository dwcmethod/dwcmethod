## experience

### DFIR

Digital forensics and incident response, with a focus on examining
artifacts, understanding what happened, and tracing activity back to
its source.

### Reverse Engineering

Binary analysis and program reversing across native Windows software,
using static and dynamic analysis to understand how a program actually
works.

### SOC

Security operations work centered around investigating events,
analyzing activity, and making sense of security telemetry.

### Cheat Development

Low-level game-related development and research, with an emphasis on
understanding the underlying software and its execution flow.
